# Glossary

ADP
: Anisotropic displacement parameter. The symmetric tensor describes the
  mean-square displacement of an atomic site in the crystallographic model.
  It is not an electron-density deformation parameter.

AO
: Atomic orbital basis function. AO ordering includes atom, shell,
  contraction, angular-momentum component, normalization, and phase; matching
  only the AO count is insufficient for a wavefunction transfer.

Asymmetric unit
: The smallest crystallographically unique set of atoms from which the
  crystal is generated by space-group symmetry.

Aspherical scattering factor
: Atomic X-ray scattering amplitude obtained from a non-spherical partitioned
  density rather than an isolated spherical-atom table.

Basis Set Exchange (BSE)
: Online basis-set repository used by the GUI. Its raw definition must be
  converted to the syntax and bookkeeping required by the consuming program.

Becke grid
: Atom-centred numerical integration grid used for molecular density and
  exchange-correlation quantities. lamaGOET exposes Tonto accuracy levels
  `very_low`, `sg-1`, `low`, `medium`, `high`, `very_high`, `extreme`, and
  `best`.

Bloch orbital
: Periodic orbital indexed by crystal momentum k. Its complex coefficients
  and phase/translation conventions cannot be represented exactly by a
  conventional finite-molecule WFN file.

CHE
: Crystal23 formal electron charge attributed to a basis shell. The element
  shell charges must sum to the all-electron atomic count for a neutral
  all-electron basis definition.

CIF
: Crystallographic Information File. lamaGOET reads structural input and
  Tonto writes final archive/fractional/Cartesian CIF products.

Cluster stockholder
: Hirshfeld partition evaluated for the finite molecular/cluster density
  supplied to Tonto.

CP2K native interface
: Direct Tonto import of CP2K real-space density, overlap and KS/Fock matrices
  plus exact MOKP basis/orbital/k-point data, without the legacy XML bridge.

CSR
: Compressed sparse row matrix representation used by CP2K's native
  real-space matrix exports.

Dynamic observed density
: Experimental model in which the reconstructed, thermally averaged atomic
  density shape is the fitted object. It is distinct from static form factors
  multiplied by separately refined ADPs.

e.s.d. / s.u.
: Estimated standard deviation / standard uncertainty. “Maximum shift/e.s.d.”
  is the largest parameter shift divided by its e.s.d. in a fit cycle.

ELMO / ELMOdb
: Extremely localized molecular orbital and the associated transfer database
  program used by the HAR-ELMO path.

FCF / FCO
: Reflection-level calculated/observed factor files written by Tonto. The FCF
  is the principal archive for independent structure-factor comparison.

Fock/KS matrix
: Matrix representation of the Hartree--Fock Fock or Kohn--Sham operator in
  the AO basis. A periodic `.47`/TREXIO validation must not substitute an
  occupied-only reconstruction for the actual available matrix.

Friedel pair
: Reflections hkl and −h−k−l. Their equivalence depends on the experimental
  treatment, anomalous scattering, and selected merge rule.

GAPW
: Gaussian and augmented-plane-wave all-electron method in CP2K. The periodic
  CP2K HAR path documented here is all-electron.

GRED
: Crystal23 formatted direct-lattice density data used as the exact static
  density anchor for supported periodic HAR and periodic XCW.

HAR
: Hirshfeld atom refinement. A theoretical density is partitioned into
  Hirshfeld atoms, their scattering factors are used to refine structural
  parameters, and the density/fit cycle repeats to convergence.

Hirshfeld atom
: Atomic density assigned by stockholder weights formed from reference
  proatom densities. It is an atom-in-molecule partition, not an isolated atom.

Hirshfeld-I
: Iterative stockholder partition in which charged or fractional-population
  proatom references are updated until their populations are self-consistent.
  It is distinct from the outer HAR geometry/density cycle and is not the model
  selected by the current `periodic` stockholder option.

IAM
: Independent-atom model using spherical tabulated atomic scattering factors.

KRED
: Crystal23 k-resolved complex orbital data used by periodic XCW. A finite
  KRED inverse transform is not a unique replacement for the exact GRED
  direct-density blocks.

λ (lambda)
: External weight controlling the diffraction contribution in an XCW/XRW
  objective. It is not a universal constant and must be selected/validated.

Merging / MERG
: Symmetry combination of repeated measured observations into unique
  reflections according to a SHELX-style code and treatment of Friedel pairs.

MOKP
: CP2K molecular-orbital/k-point print format carrying basis, k-point,
  occupation, energy and orbital coefficients required by the native path.

Native interface
: A path that reads the producing program's own density/orbital/matrix outputs
  directly. “Native” does not waive the need for atom/AO/cell validation.

Observed-density reconstruction
: Regularized reconstruction using phased experimental residual information,
  a prior, symmetry, positivity/electron-count conditions, and held-out
  validation. It is not a unique experimental wavefunction.

Periodic stockholder
: Hirshfeld partition whose procrystal/reference environment includes
  crystalline translations rather than only a finite cluster. The current
  implementation uses fixed neutral proatoms (periodic H0), not Hirshfeld-I.

Periodic XCW
: Fixed-geometry Tonto optimization of a periodic k-resolved wavefunction
  under an X-ray restraint, anchored to a matched direct periodic density.

Promolecule
: Sum of reference proatom densities used to construct stockholder weights.

R factor
: Conventional agreement measure between observed and calculated reflection
  amplitudes for a stated population. The population suffix and scale must be
  reported.

Reflection lifecycle
: The ordered processing from immutable unmerged measurements through weak
  filtering, symmetry merging, model-dependent zero pruning, fitting, and
  final artifact generation.

Residual density
: Fourier difference between observed and model structure factors after the
  stated scaling/selection. It contains model, data, truncation, and systematic
  effects, not only missing chemical density.

R-free / held-out reflections
: Deterministically excluded observations used to assess generalization or
  select regularization without minimizing the same data used for fitting.

Rhombohedral setting
: Choice of hexagonal versus primitive rhombohedral crystallographic setting.
  It affects the cell/symmetry mapping and must match all program interfaces.

SCCC
: Self-consistent cluster charges. Tonto-derived environmental charges and an
  external molecular optimization are alternated until the theoretical
  embedded geometry/charges converge.

Site symmetry
: Subgroup of space-group operations that leaves an atomic site invariant.
  Partitioned density and refined parameters must respect the site's allowed
  symmetry.

Stockholder model
: Rule assigning the total density to atoms through reference-density weights;
  lamaGOET exposes cluster and periodic choices where the workflow supports
  them.

Systematic absence
: Reflection constrained to zero by symmetry for the relevant model. In the
  aspherical workflow the zero test is repeated from the full unmerged data
  after every new partition.

TOLINTEG
: Crystal23 integral-screening thresholds. They can expose or suppress
  numerical linear dependence but do not turn an unsuitable molecular basis
  into a robust periodic basis.

TREXIO
: Interoperable wavefunction container used by lamaGOET for exact periodic
  output. It is distinct from a finite cluster `.47`, WFN, or WFX file.

Unmerged observations
: Original individual measured intensities and uncertainties before symmetry
  averaging. They are the immutable source for each reflection lifecycle.

WFN / WFX / `.47`
: Finite-molecule wavefunction and NBO interchange formats. They are not exact
  containers for an infinite periodic Bloch state.

XCW / XRW
: X-ray constrained or restrained wavefunction calculation performed by
  Tonto at fixed geometry. Contemporary literature emphasizes that the X-ray
  term acts as a restraint in the common implementation; lamaGOET retains XCW
  terminology for compatibility.

XWR
: X-ray wavefunction refinement: in this manual, a HAR geometry refinement
  followed by a fixed-geometry XCW calculation.
